# Git & GitHub Practice

A sandbox repository from my data analytics coursework, used to practise the Git workflow before
applying it to real project repos. It holds no analysis — that lives in the project repositories.

## What I practised here

- Initialising a repository and making the first commit
- `git add` / `git commit` / `git push` against a remote
- Writing commit messages that describe the change rather than the file
- Branching, merging, and resolving a conflict
- `.gitignore` for data files, notebook checkpoints, and credentials
- Cloning and pulling to keep a local copy in sync

## Where this workflow is actually used

| Repository | What it contains |
|---|---|
| `fitness-subscription-analytics` | Retention, CAC payback and cohort analysis on 9,300 subscribers |
| `customer-churn-prediction` | Logistic regression vs decision tree churn models |
| `olist-ecommerce-eda` | Exploratory analysis of 99,441 Brazilian e-commerce orders |
| `shopify-app-store-analysis` | Power BI report on 500 apps and 8,240 reviews |
| `video-game-sales-python` | Core Python fundamentals on a sales dataset |
